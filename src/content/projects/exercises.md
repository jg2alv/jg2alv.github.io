exercises is my programming practice archive, organized around the courses and topics I explored. Rather than a single application, it brings together small programs that put language features and development patterns into concrete interfaces, tools, and prototypes.

Examples include a JavaScript pizza catalog with size and quantity selection, cart updates, and pricing calculations; an Electron utility that wires image-optimization requests through IPC; and Go and C# exercises using interfaces and shared contracts. Other directories explore JSON serialization, numerical iteration in Racket, and early Unity and SwiftUI interfaces.

The recurring challenge was translating concepts across tools with different execution and state models. These exercises connect event-driven browser programming, object-oriented contracts, and functional numerical iteration. The archive preserves both implementations and unfinished starters, so its scope is a record of practice rather than a claim that every exercise is complete.

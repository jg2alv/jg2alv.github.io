Games brings together five classic game prototypes implemented as separate C# console applications: Tic-Tac-Toe, Hangman, Snake, Space Invaders, and Chess. Each project uses the .NET console for its interface, with text boards, cursor positioning, colors, and keyboard input rather than a game engine.

The turn-based games explore board state, input validation, and player alternation. Snake adds continuously updated movement, body segments, food, growth, and collision checks. Space Invaders introduces player and enemy entities, projectiles, spawning, and scoring code, while Chess models pieces, ownership, board coordinates, and movement choices.

The collection shows different ways to organize small interactive programs with classes, enums, collections, and update loops. These are prototypes with incomplete rules and edge cases, particularly in Chess and Space Invaders, so the project is presented as a set of programming experiments rather than a finished game suite.
